# Learning modules

Interactive, bilingual learning modules built from lecture material. They are published on the website under `/learn/` and are generated by `python scripts/tentopics.py site`.

Everything runs in the reader's browser: no login, no grading, nothing is stored or sent. Only the chosen perspective ("I am …") is remembered locally.

## Structure

```
learn/
  <module-id>/        e.g. history
    de.md             German version
    en.md             English version
    *.svg             diagrams included with ```include
```

Both language files share the same `<module-id>`, and the pages link to each other.

## Front matter

Each file starts with a YAML block:

```yaml
---
title: "Geschichte und Entwicklung der Medizinischen Informatik"
summary: "One or two sentences shown under the title and in search results."
duration_minutes: 30
level: "Einstieg"                    # free text, e.g. Einstieg / Introductory
audiences: [med, cs, clin, tech, pat]
order: 1                             # position in the learning path
builds_on: []                        # module ids this module builds on, e.g. [history]
course: "Einführung in die Medizinische Informatik"   # optional: the course it comes from
author: "Markus Wolfien"
objectives:
  - "…"
readings: [haux2006, berg2001]       # reference ids from data/references.yaml
related_topics: [ehr-cis, cdss]      # topic ids from data/topics.yaml
source: "Lecture the module is based on"
---
```

Audiences:

| id | German | English |
|---|---|---|
| `med` | Medizinstudierende | Medical students |
| `cs` | Informatikstudierende | Computer science students |
| `clin` | Ärzt:innen & Pflege | Clinicians & nurses |
| `tech` | Informatiker:innen | Computer scientists |
| `pat` | Patient:innen & Interessierte | Patients & the public |

## Content

Write normal Markdown (headings, lists, tables, quotes). Cite references with `[@id]`, as in `data/topics.yaml`, and link to another module in the same language with `[[module-id]]` (e.g. `[[history]]`); the link shows that module's title.

## Learning path

Modules are listed in the order given by `order`. A module with `builds_on: [history]` shows "Builds on …" at the top, and the module it builds on shows "Continue with …" at the end, so readers can follow the path in both directions. Use `[[module-id]]` in the text to pick up concepts from earlier modules.

## Interactive elements

Interactive elements are fenced blocks:

**Quiz** – one question, the answer is chosen from a dropdown. The explanation appears after a correct answer.

````
```quiz
question: "Was wurde in Krankenhäusern vermutlich **zuerst** digitalisiert?"
options:
  - "Komplexe Therapieentscheidungen"
  - "Abrechnung und Leistungsdokumentation"
answer: "Abrechnung und Leistungsdokumentation"
explain: "Optional: why this is the answer."
```
````

**Match** – several items, each with a dropdown of the same options.

````
```match
question: "Welches System macht was?"
options: ["KIS", "LIS", "PACS"]
items:
  - item: "Laborwerte validieren und übermitteln"
    answer: "LIS"
  - item: "Radiologische Bilddaten speichern und anzeigen"
    answer: "PACS"
explain: "Optional explanation shown when all items are correct."
```
````

**Reflect** – an open question with a text field (not stored) and hidden sample answers.

````
```reflect
question: "Welche Aufgabe sollte niemals vollständig delegiert werden?"
intro: "Optional sentence before the answers."
answers:
  - "die Therapieentscheidung"
  - "das Gespräch über schlechte Nachrichten"
```
````

**Persona** – a "why this matters for you" box for one audience. Boxes that follow each other are shown side by side; readers can filter them with the "I am …" selector.

````
```persona med
Im Stationsalltag werden Sie …
```
````

**Timeline** – a vertical timeline. With `collapsed`, it is hidden behind a "show solution" link, e.g. after a guessing exercise.

````
```timeline
title: "Grobe Entwicklungslinien"
collapsed: "Auflösung: die Zeitachse anzeigen"
events:
  - when: "1960er–70er"
    what: "EDV für Verwaltung"
```
````

**Case** – a box for a running patient case that the module follows from section to section.

````
```case
Ein **62-jähriger Raucher** kommt zur hausärztlichen Kontrolle …
```
````

**Include** – inline an SVG file from the module folder. Use the CSS classes `node`, `hub`, `edge`, `label`, `small`, `hub-label` and `arrowhead` (for arrow markers) so the diagram follows the light and dark theme.

````
```include triangle-de.svg
```
````

## Checking a module

```sh
pip install pyyaml markdown
python scripts/tentopics.py validate   # checks front matter, answers, references, topic ids
python scripts/tentopics.py site       # builds the site into _site/
python -m http.server --directory _site
```

Then open http://localhost:8000/learn/.
