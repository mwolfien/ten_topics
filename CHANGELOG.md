# Changelog

This collection is a living resource. Notable changes to its content and structure are listed here.
Each release on GitHub corresponds to a citable version (see [CITATION.cff](CITATION.cff)).

## 2026-09

### Content
- Added 40 references published 2024–2026, mostly from Q1 journals, across all ten topics and the additional topics, e.g., ethics and regulation of LLMs, the EU AI Act, ambient AI scribes, federated learning governance, the European Health Data Space, LLM-based information extraction, FHIR and LLMs, OHDSI/EHDEN, data quality for AI, LLMs in clinical decision-making, retrieval-augmented generation, dashboards, research infrastructures, and disease maps.
- Linked the published article ([Wolfien et al. 2023](https://doi.org/10.2196/45948)).
- Fixed malformed and unregistered DOIs, normalized links to `https://doi.org/`, removed an empty link and fixed typos.

### Structure
- Content moved to machine-readable files: `data/topics.yaml` and `data/references.yaml`. `README.md` is now generated by `scripts/tentopics.py`.
- Added automated checks: data validation, README consistency, and monthly DOI/link checks.
- Added a CC BY 4.0 license, `CITATION.cff`, contribution guidelines, and issue and pull request templates.

## 2023

- Initial collection accompanying the article "Ten Topics to Get Started in Medical Informatics Research" (J Med Internet Res 2023;25:e45948), including additional topics on computational infrastructure and disease maps, and a literature update for Q3 2023.
